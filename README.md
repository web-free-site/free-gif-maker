# Free GIF Maker

Turn local still images into an animated GIF in your browser. Based on [Gifio](https://github.com/dabirdwell/gifio) (MIT).

- Live target: `https://free-gif-maker.web-free.site`
- Build: `npm install && npm run build`
- Preview: `npm run preview` then open http://localhost:4173
- Smoke test: run preview, then `npm run test:smoke`

Agent instructions: `AGENT_BRIEF.md`.
